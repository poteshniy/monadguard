Use it in your agent

One call before connecting. Fails closed: CRITICAL, WARN, a stale verdict or a tool nobody scanned all stop the connection.

npm i monadguard

import { gate } from 'monadguard';
await gate({ kind: 'mcp', name: 'memory-server', origin: 'npm:@modelcontextprotocol/server-memory' });
await client.connect(transport);   // only reached when a fresh CLEAN verdict exists
